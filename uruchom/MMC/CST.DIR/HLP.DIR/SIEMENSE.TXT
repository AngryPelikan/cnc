1. REQUIREMENTS:
================

In order to be able to use the standard cycle version, NC software version 5.3
and higher for 840D or 3.1 and higher for 810D will be required.
CYCLE800 will require NC software version 6.3.

Machine data of the control are by default configured in a way that these cycles
can be loaded and executed. Please see items 4. and 6. for notes on important
machine data settings.

They contain the cycles, data and macro definitions for the cycles, the files
for cycle operator control for control types 840D/840Di/810D with HMI Embedded

The subdirectories of the floppy disks contain all HMI configurations for the
individual files required.

Directory HMI_EMB\TOOLS contains the files for the help screens of the cycles
with HMI Embedded, SW6.2 and higher.

4. MACHINE DATA SETTINGS AND START-UP:
======================================

4.1.  Memory-configuring machine data for user cycles:
If user cycles are loaded to the control in addition to the Siemens cycles, it
is recommended to increase the two memory-configuring machine data.

        18170   $MN_MM_NUM_MAX_FUNC_NAMES
        18180   $MN_MM_NUM_MAX_FUNC_PARAM

The following values will be required for executing the Siemens cycles:

        18170   $MN_MM_NUM_MAX_FUNC_NAMES = 40
        18180   $MN_MM_NUM_MAX_FUNC_PARAM = 450.

4.2.  Start-up for thread recutting for HMI Advanced:
Thread recutting requires operation in basic JOG display. For this purpose,
softkey HS8 "Thread recutting" in file MA_JOG.COM has to be activated.
Open file MA_JOG.COM and remove the semicolon in the following lines:
   ;HS8=($80720,,se1)
   ;PRESS(HS8)
   ;LM("GENS","DREHEN2.com")
   ;END_PRESS
The file is stored in directory "Standard cycles".
The softkey is now active.
	
4.3.  Start-up for thread recutting for HMI Embedded:
Thread recutting requires operation in basic JOG display. For this purpose,
softkey HS8 "Thread recutting" in file COMMON.COM has to be activated.
Open file COMMON.COM and delete the ";" in front of SC108. The file is stored in
directory "User cycles".
MMC has to be restarted afterwards.


5. LOADING THE CYCLES TO THE CONTROL:
=====================================

5.1. Special notes on how to load the cycles with HMI Embedded configuration:
RS-232-C user interface. The files are automatically loaded to the correct 
directory in the file system.

Before being able to execute the cycles, you have to execute a Power ON of the
control after having loaded the cycles.

5.2. How to upgrade these cycles in HMI Advanced up to SW 6.2:

All *.SPF files in directory HMI_ADV are available as punched tape archive while
files *.COM, *.AWB and *.LST are stored in PC format.
Read-in to the control is executed in the Services area with function "Data
in" either directly from the floppy disk or via an RS-232-C interface.
The cycles will be transferred automatically to directory "Standard cycles" and
the file from subdirectory DEFINE to directory "Definitions". (You are not
allowed to use function "Copy" from the floppy disk !).

5.3. How to upgrade these cycles in HMI_Advanced SW 6.3 or higher:

In HMI_Advanced SW 6.3 or higher, the cycles are stored as archives under
 "Archives", "Cycle archives". 
To upgrade the cycles, archive SC_ARC63.ARC must be read in from directory 
HMI_ADV. It will unpack the cycle archives and overwrite the available archive
of the previous cycle version.
The following archives belong to cycle version 6.4:
ARC.DIR\CYC.DIR\CYCCUST_GR.ARC		Archive file of all user cycles with
German comments
            ...\CYCCUST_UK.ARC		Archive file of all user cycles with
 English comments
	    ...\CYCLES.ARC		Archive file of all cycles
	    ...\CYCLIST.ARC		Archive file of all cycle package lists (HMI
 SW 6.3 and higher)
	    ...\CYCMILL.ARC		Archive file of all cycles for Milling technology
	    ...\CYCTURN.ARC		Archive file of all cycles for Turning technology (without drilling cycles) 
 	    ...\DEFINES.ARC		Archive file of the definition files
	    ...\SCSUPP.ARC		Archive file of all cycle support files
	    ...\SIEMENSD.ARC		Archive file of siemensd.txt					
	    ...\SIEMENSE.ARC		Archive file of siemense.txt	
	    ...\VERSION.ARC		Archive file version cycle version	
The archive TOOLCARR.ARC in cycle version SW 6.3 will no longer be required for
this cycle version. This archive should therefore be deleted before upgrading.
The TOOLCARR cycle is stored language-dependent in archive CYCCUST_GR.ARC or
CYCCUST_UK.ARC. 
The archives from the HMI cycle archive must now be read in technology-dependent
(turning, milling...) or language-dependent via "Data in". 

5.4. Special notes on how to install the cycles:

Transfer the cycles to the control file by file. You are not allowed to use the
PCIN function "Mark several files and transfer in one block"!


6. SPECIAL NOTES ON HOW TO USE THIS CYCLE VERSION:
==================================================

1. Machine data setting for stock removal cycle CYCLE95:
For this version and higher, stock removal cycle CYCLE95 requires the following
machine data settings:
        MD 11410 $MN_SUPPRESS_ALARM_MASK = 02H
        MD 20240 $MC_CUTCOM_MAXNUM_CHECK_BLOCKS = 4

2. Cycles 6.4 can be used for 840D with NCU version 6.3 and higher or for
810D with CCU version 6.3 and higher. The following special requirements
apply:
- CYCLE800 cannot be executed and requires NCK 6.3 or higher
- The following machine data settings are required
  MD 28020 MC_NUM_LUD_NAMES_TOTAL = 400         for pre-recompiling the cycles
  MD 20250 $MC_CUTCOM_MAXNUM_DUMMY_BLOCKS=5     for CYCLE72
  MD 9424 MA_COORDINATE_SYSTEM = 1              for displaying WCS of CYCLE95

3. How to activate the screens for swivel cycle CYCLE800 in HMI:
Operating the swivel cycle includes an entry screen in the cycle support and a
screen in the 'Start-up' operating area used to start up the kinematics and the
rotary axes.
The screen in the 'Start-up' operating area must be activated as follows. 
For HMI Embedded:
  The softkey HS14 "Swivel cycle" in file COMMON.COM must be activated.
  Open file COMMON.COM and delete the ";" in front of SC616. 
  The file is stored in the directory "User cycles". Afterwards an NC reset is
 required.
For HMI Advanced:
  Open file startup.com and delete the ";" in front of the following lines:
	;HS14=($82084,ac7)
	;PRESS(HS14)
	;LM("SCHWENK1a","SCHWENK1.com")
	;END_PRESS
  The file is also stored in the directory "Standard cycles".
  Restart HMI Advanced after these two changes.


7. New functions in SW 6.4:
===========================

7.1. New cycle: CYCLE60 engraving cycle

With the new engraving cycle CYCLE60 any single-line text can be engraved. The
 basic form of the characters is fixed, while the width of the lines depends
 on the tool. Via different input parameters, the font size, position and
 alignment of the text on the part can be selected. The text can be max. 91
 characters long and is transferred to the cycle as string parameter.
A support screen for the cycle will not be available before SW 6.5.

7.2. How to handle ST_CUST.SPF

User cycle ST_CUST.SPF SW 6.4 and higher is called by many standard cycles.
It must be loaded to the control.
The cycle is delivered language-dependent with German or English comments
 together with the archives CYCCUST_GR.ARC or CYCCUST_UK.ARC. It must be adapted
 by the machine OEM, if required.

7.3. Cycle subroutine MESSAGE deleted

In SW 6.4 and higher the cycle subroutine MESSAGE will no longer be required.
 The messages are output in the cycles directly through MSG command.
For SW upgrades, the cycle MESSAGE.SPF can be deleted from directory CST.DIR.

7.4 Changes / extensions in CYCLE800

7.4.1. Start-up screen for swiveling

- New rotary axes mode "semi-auto"
  Mode "semi-auto" is used to fade out messages 62180/62181 (display of angle
 values to be set).
  Application: Manual rotary axes, which are positioned to the calculated angle
 via an appropriate mechanical system.
  For this purpose, the machine OEM has to modify the user cycle TOOLCARR
 accordingly.
  (marks _M21.. for manual rotary axes).
- New rotary axes input field "Offset kinematics"
  Input field "Offset kinematics" can be used to enter the offset value of
 rotary axis 1 ($TC_CARR24[n]) or rotary axis 2 ($TC_CARR25[n], if the position
 of the rotary axes does not equal 0 in the inital setting of the kinematics.
- Input field "automatic offset" for rotary axes with Hirth tooth system is no
 longer available.

7.4.2. Note on kinematics (inclinable head/mixed kinematics) with Hirth tooth
 system:
  Depending on the active plane (G17,G18,G19) the command TOROT (or TOROTX,
 TOROTY) is programmed in CYCLE800 to calculate(in NCU) the compensation frames
 of the Hirth tooth system (G-Gruppe 53). 
  If the Hirth tooth system causes the programmed rotation to deviate from the
 possible positions of the rotary axes, a TOOLFRAME will be created for
 inclinable head kinematics and mixed kinematics (see HMI active WO/details tool
 reference).
  The calculation depends on setting data SD 42980 $SC_TOFRAME_MODE and on
 machine data MD 21110 $MC_X_AXIS_IN_OLD_X_Z_PLANE=1 (standard)
  Set the kinematics (inclinable head/mixed kinematics) with Hirth tooth system
 setting data SD 42980 $SC_TOFRAME_MODE=1000 ! 
  If the compensation frame (TOOLFRAME) shall be maintained after reset or
 programm exit, set MD 20150 $MC_GCODE_RESET_VALUES[52]=2, for G17 TOROT (for
 G18=3  TOROTY,bei G19 =4 TOROTX).

7.5. New user cycle CYC_832T for CYCLE832

If the machine OEM requires any additional behavior of CYCLE832 that goes beyond
 the technological adjustments, the required changes can be made in cycle
 CYC_832T. For this purpose, CYC_832T should be copied to directory CMA.dir (HMI
 supplier) and loaded to the NCU.
CYC_832T is a basic program. Any changes must be documented by the machine OEM.
 In case of any changes made in CYC_832T , it will not be necessary to change
 CYCLE832. 

Parameter
CYC_832T(_ASVS,_FACTOR,_OVL_on)

_ASVS Machine-specific adjustments can be made at the marks _M0 through _M4.
      _M4 = Init CYCLE832 is called prior to the program run of CYCL832 
      _M0 = Deselection of CYCLE832
      _M1 = Finishing cut machining
      _M2 = Rough-finishing machining
      _M3 = Roughing machining

_FACTOR - factor of rotary axis tolerance
_OVL_on - 1=overload factor MD $MA_MAX_ACCEL_OVL_FACTOR is adjusted  0=is not
 adjusted.
